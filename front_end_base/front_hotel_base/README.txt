FRONT-END BASE — HOTEL / POUSADA

Este material é apenas uma base visual para o exercício.
Os alunos devem desenvolver o backend em PHP + PostgreSQL + PDO.

Arquivos:
- index.html
- hospedes.html
- quartos.html
- servicos.html
- reservas.html
- css/style.css

Os dados exibidos nas tabelas são exemplos estáticos.
Os alunos devem substituir pelos dados retornados pelo PHP.

Os action dos formulários são sugestões de organização e podem ser
alterados de acordo com a estrutura de backend escolhida pelo grupo.

Bootstrap 5.3 e Bootstrap Icons podem ser usados via CDN.
